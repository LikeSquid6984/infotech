# Viksit Bharat – Infotech Project

This is my Infotech project for Class X. It covers India's journey from 1947 to 2047 — focusing on achievements in space, defence, and technology.

**Live Site** – https://likesquid6984.github.io/infotech/

**GitHub Repo** – https://github.com/LikeSquid6984/infotech

---

## About the Project

Built using HTML, CSS, and JavaScript. No external frameworks were used.

The website includes:
- A loading screen with the Indian tricolour
- A sticky navbar with smooth scroll
- A chakra dial timeline showing milestones from 1947 to 2047
- Animated count-up statistics
- A section on Operation Sindoor and India's air defence systems
- A Vision 2047 section based on NITI Aayog's goals

All photographs are sourced from Wikimedia Commons. All statistics are linked to official government press releases at the bottom of the page.
